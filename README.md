# Helpshift

Helpshift SDK 7.11.1 packaged for Swift Package Manager. Requires iOS 16 or later.

Add `https://github.com/suunto-git/Helpshift.git` as a package dependency, select version `7.11.1`, and link the `Helpshift` product.

The XCFramework includes device and simulator binaries. Bitcode is removed and localization resources follow the app's supported language list.

The commercial license reference in `LICENSE` is preserved from the upstream Helpshift 7.11.1 CocoaPods specification.
